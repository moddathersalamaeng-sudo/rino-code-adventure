# Rino World — عالم رينو v0.3

مغامرة تعليمية ثلاثية الأبعاد لريان (رينو)، مع شخصية كرتونية مستوحاة من صورة مرجعية: شعر بني، تيشيرت أبيض، جينز، شنطة كروس بيج وجزمة بعجلات قابلة للتركيب. الرسومات أصلية مبنية بمجسّمات؛ ليست نسخة فوتوغرافية. الصورة الأصلية وتاريخ الميلاد غير مضمّنين.

## رحلة اللعب

| الرحلة | البحث والحساب والإنجليزي | النشاط |
|---|---|---|
| ميناء المستكشف | شحنات 248 + 176، أطقم عجلات 6 × 4، معنى bag | مركب يمر بثلاث نقاط بحرية |
| محطة الرحلات | زمن من 10:30 إلى 11:15، 12 × 3، قراءة تعليمات الأمان | قيادة قطر على سكة وثلاث محطات |
| مطار رينو | حقائب 8 × 7، معنى CLEAR، شرط AND | توجيه طيارة عبر حلقات مع إقلاع تلقائي |
| جزيرتي أنا | 7 × 4 = 28، التكرار والبناء | بناء جسر وتجربته بالمشي |

كل رحلة تتطلب العثور على ثلاث لوحات داخل العالم قبل مكتب التحديات، والإجابة عن ثلاث أسئلة قبل فتح المركبة، ثم المرور بنقاط القيادة بالترتيب. مفيش وقت محدد ولا عقاب على الغلط: تلميح ثم محاولة أخرى وشرح للإجابة الصحيحة. دفتر المستكشف يحتفظ بالأدلة للرجوع إليها أثناء السؤال. كل المناطق متاحة من البداية ليستكشفها الطفل مع ولي أمره. المدة الفعلية تعتمد على سرعة القراءة والاستكشاف؛ يمكن تقسيم الرحلة إلى جلسات.

مستوى الأسئلة بداية تدريبية لسن 9 سنوات والصف الرابع بتعليم إنجليزي، وليس اعتمادًا لمنهج مدرسة بعينها. عدّلوا المحتوى حسب مستواه. قيادة وسائل النقل مبسطة وليست محاكاة تدريب واقعية.

## التشغيل

الرابط المنشور هو الأسهل على الموبايل. محليًا تحتاج Node.js: شغّل `npm start` من المجلد ثم افتح `http://localhost:4173`. لا تفتح index.html بالضغط المزدوج؛ وحدات JavaScript تحتاج خادم HTTP. المكتبة الرسومية Three.js 0.186.1 موجودة داخل vendor/ برخصة MIT، لذلك لا يحتاج اللعب المحلي للإنترنت ولا لتثبيت حزم. يحتاج متصفحًا يدعم WebGL.

الأسهم أو WASD للحركة، E للتفاعل، V لتركيب/خلع العجل، R للرجوع لمكان آمن. عند القيادة: W أو ↑ للأمام؛ S أو ↓ للخلف، والسهمان الجانبيان لتوجيه المركب والطيارة. الكاميرا تدور بسحب المشهد. على الموبايل أزرار لمس، ويفضل الوضع الأفقي. زر التكبير يعمل عندما يدعم المتصفح Fullscreen API.

## أول جلسات مع رينو

1. خليه يختار مكانًا ويستكشف، ويسجل الأدلة. اسأله: «عرفت الإجابة منين؟».
2. عند الغلط، اقرأ التلميح معاه وخليه يشرح طريقته قبل الإجابة.
3. جرّب فرق المشي والعجل، وخليه يقول أي وضع أنسب للتوقف عند لوحة.
4. بعد الرحلات الثلاث خليه يتوقع هل ثلاث قطع جسر تكفي، ثم يجرب ويحسب العدد المطلوب.
5. أول تعديل في المصدر: غيّر دليلًا وسؤالًا من activities.js مع الحفاظ على تطابقهما.

## كيف يكمل بنفسه؟

- `activities.js`: أفضل بداية؛ البيانات والنصوص والأسئلة والاختيارات. answer يبدأ من صفر. غيّر الدليل إذا غيّرت أرقام السؤال.
- `world.js`: المجسمات والحركة والكاميرا والمركبات والتفاعل والحفظ.
- `style.css` و`index.html`: الواجهة العربية وأزرار التحكم.
- `build.cjs`: ينسخ الملفات المطلوبة فقط إلى dist للنشر.
- `.openai/hosting.json`: هوية الاستضافة؛ حافظ عليها عند التحديث.

مختبر الجسر يربط قيمة عددية بفكرة repeat مباشرة. ليس محرر كود JavaScript عامًا. تصدير التصميم ينزّل JSON للنسخ الاحتياطي والقراءة؛ لا يوجد استيراد تلقائي له. لإضافة قصة جديدة الآن عدّل رحلة موجودة؛ إضافة منطقة رابعة كاملة تحتاج توسعة بناء العالم وحالة التقدم في world.js مع ولي الأمر.

خطة التحديث التالية: مهمة توصيل طرود يكتبها رينو، ثم أوامر مركبة قابلة للترتيب، ثم محرر مشاهد وأسئلة داخل اللعبة. هذه أفكار لاحقة، وليست وظائف موجودة في v0.3.

## الحفظ والخصوصية

التقدم وتصميم الجسر محليان في نفس المتصفح تحت rino-world-v3. لا حسابات داخل اللعبة أو دردشة أو إعلانات أو مشتريات أو رفع نتائج. مسح بيانات المتصفح أو تغييره قد يفقد التقدم. إعادة الضبط تطلب خطوة تأكيد داخل اللعبة. الاستضافة قد يكون لها دخول أو إعدادات وصول منفصلة. لا تضع معلومات الطفل الشخصية في الأسئلة أو المستودع.

## البناء والتحقق

`npm run check` يفحص صياغة الملفات. `npm run build` يجهز dist. اختبارات اللعب أثناء التطوير شملت: قفل الأسئلة حتى جمع الأدلة، المحاولة الخاطئة ثم الصحيحة، المسارات الثلاثة للمركبات بالترتيب، اكتمال الرحلات، جسر قصير يفشل وآخر ينجح، وتركيب وخلع العجل. هذه اختبارات منطق ومحاكاة؛ تجربة جهاز الموبايل الحقيقي تبقى مهمة بعد فتح الرابط.

مصدر الكود جاهز لحفظه في GitHub. استضافة Sites مستقلة عن إنشاء مستودع GitHub جديد. لم يُنشأ مستودع GitHub بمجرد نشر رابط اللعبة.
